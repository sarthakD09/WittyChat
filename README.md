Overview

WittyChat is an open-source, real-time chat application built with React, Vite, and Firebase, designed to streamline the development of secure and scalable messaging platforms. It offers a modular architecture with rich features for user authentication, media sharing, and dynamic UI components.

Why WittyChat?

This project simplifies building real-time communication tools by integrating Firebase's backend services with a modern React frontend. The core features include:

🛡️ Security & Privacy: Firebase security rules protect user data and ensure proper access controls.
⚡ Fast Development: Vite-powered setup enables rapid builds and hot module replacement.
💬 Real-Time Messaging: Firebase Firestore syncs chat data instantly across clients.
📸 Media Sharing: Seamless image uploads and downloads via Firebase Storage.
🚀 Automated Deployment: GitHub Actions streamline continuous delivery to Firebase Hosting.
